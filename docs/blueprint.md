# **App Name**: AISight

## Core Features:

- Website Visibility Test: Accept a website URL and a prompt from the user to test its visibility across different AI platforms.
- AI Platform Integration: Test the website visibility using the ChatGPT, Copilot, Perplexity and Grok platforms.
- Visibility Detection Tool: An AI tool that intelligently analyzes responses from AI platforms to determine if a given website is mentioned within the text.
- Real-time Test Results: Display the results of the visibility test for each platform, indicating whether the website was found or not.
- Historical Data Storage: Save the results of each test, including the website, prompt, and visibility status for each platform, without storing in Firestore.
- Test History Visualization: Display a chart and list of previous tests performed, showing the website tested, prompt used, and a summary of visibility across platforms.

## Style Guidelines:

- Primary color: Deep violet (#7950F2) to convey intelligence and insights.
- Background color: Dark gray (#212121) for a modern and focused feel.
- Accent color: Electric purple (#BE79DF) for highlighting important elements.
- Body and headline font: 'Inter' (sans-serif) for clear and modern readability.
- Use minimalist icons from Lucide React for key actions and status indicators.
- Use a grid-based layout to organize the AI platform test results, test history and chart of historical data.
- Subtle loading animations and transitions to improve user experience.
